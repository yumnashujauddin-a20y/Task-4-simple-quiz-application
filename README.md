# Simple Quiz Application

## Description
A simple and interactive quiz application built using HTML, CSS, and JavaScript. Users can answer multiple-choice questions, check their answers, and view their final score.

## Features
- Multiple-choice questions
- Interactive answer selection
- Instant feedback on answers
- Score tracking
- Final score display
- Simple and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
simple-quiz-application/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start answering the quiz questions and view your score.

## Learning Objectives
- Understand HTML page structure.
- Style a web application using CSS.
- Use JavaScript to handle user interactions.
- Practice conditional statements, event handling, and score calculation.
